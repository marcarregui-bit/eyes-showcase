What it does today

Eight things, all of them running

Not a roadmap. Every item below is exercised by the test suite and demonstrable on the machine it was built on.

Escritorio

It drives Windows, not an API

Opens apps, types, clicks, navigates, reads the screen. Word, Excel, PowerPoint and Outlook through COM; LibreOffice through UNO when Office isn't there. The browser through CDP. No RPA recorder, no brittle coordinates.

Verificación

Every action is checked against the world

A universal oracle reads the effect of an action — object state, then UI tree, then pixels — and a step is only closed when the effect is confirmed. A sentence is not evidence; a file on disk is.

Entregables

It produces documents, not summaries

A drafter with a data contract, a judge that can send it back, and a verified PDF on disk. If the composer can't run, it says so and hands you the result another way instead of declaring the job done.

Análisis

Big spreadsheets, answered locally

A local columnar store (DuckDB) ingests whole workbooks — millions of rows — and answers questions in place. The data never leaves the machine; only a pseudonymised schema does.

Privacidad

What crosses the wire is written down

Pseudonymisation with an ephemeral in-RAM key, an allowlist on generated SQL, no disk or network reachable from a query, exfiltration verbs classified and confirmed. Voice is local by default.

Memoria

It learns this machine, not the internet

A local index of your paths and a click memory that remembers what worked where, so the second time is faster than the first.

Control

Stoppable, and honest about it

Pause, resume and stop at any point. A halted batch reports how many actions ran. Destructive keys are blocked when it can't verify what's in front — including its own window and your terminal.

Degradación

Missing capability is announced, not hidden

A pre-flight check at startup states what this machine can actually deliver today: no spaCy, no Office, no local model. Silence about a missing capability is the failure mode it was built to avoid.

The difference

It keeps a register, and the register can say no

On the public desktop benchmark (OSWorld) the state of the art sits near 20% success against a 72% human baseline. The unsolved problem is not dexterity — it is that agents don't recognise their own failures. Eyes writes down what it has proven, per application, with the evidence that proved it. A capability with one single success is flagged as untested ground. A capability you vetoed stays vetoed, even if the oracle later succeeds.

What it does not do

The part most pages leave out

A product whose whole thesis is not overclaiming has to start here.

Windows 10/11 onlyNo macOS, no Linux. It talks to Win32, COM and UI Automation.
Spanish interfaceThe agent thinks in Spanish today. Not a hard constraint, but it's the truth right now.
No installer yetIt runs from its own folder. It has never been installed on a second machine — and until it is, we don't claim it works there.
No production customersThree months old, one person, zero paying users. The tests are real; the traction isn't there yet.
Source is not publicThis repository is a showcase. The code is proprietary and stays private.

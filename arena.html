The numberEl número

Six of fifteen, and nothing claimed that wasn’t done

Seis de quince, y nada reclamado sin hacerlo

Windows Agent Arena is a benchmark from Microsoft and Carnegie Mellon: 154 tasks on a real Windows 11 machine, graded by scripts that inspect the final state of the system. What the agent claims it did counts for nothing.

Windows Agent Arena es un banco de pruebas de Microsoft y Carnegie Mellon: 154 tareas sobre un Windows 11 real, corregidas por scripts que miran el estado final de la máquina. Da igual lo que el agente diga que hizo.

What this number does not sayLo que este número no dice
  • Fifteen tasks are not a measurement of the whole. The confidence interval is enormous. At fifty it would start to mean something.
  • The sample is deliberately biased toward unexplored task domains. It was built to find defects, not to estimate the rate across all 154.
  • On some tasks Eyes didn’t use the GUI. Asked to open Notepad and save a file, it wrote the file directly. The evaluator only inspects the file, so it scored as a success — but it isn’t the same thing.
  • There is no comparable baseline. The paper’s reference agent scores 0 today: its response parser is tuned for a model that no longer exists.
  • Quince tareas no son una medición del conjunto. El intervalo de confianza es enorme. Con cincuenta empezaría a significar algo.
  • La muestra está sesgada a propósito hacia dominios sin explorar. Servía para encontrar fallos, no para estimar la tasa de las 154.
  • En algunas tareas Eyes no usó la interfaz. Cuando le pedían abrir el Bloc de notas y guardar un fichero, escribió el fichero directamente. El evaluador sólo mira el fichero, así que lo puntuó como acierto — pero no es lo mismo.
  • No hay línea base comparable. El agente de referencia del artículo saca 0 hoy: su lector de respuestas está afinado para un modelo que ya no existe.
The three outcomesLos tres desenlaces

The register can say “I don’t know”

El registro puede decir «no lo sé»

Most agents have two states: done or failed. When they can’t verify something, it falls into the optimistic one. Eyes has three, and the third is what changes how far you can trust the other two.

Casi todos los agentes tienen dos estados: hecho o fallido. Cuando no pueden verificar algo, cae en el optimista. Eyes tiene tres, y el tercero es el que cambia hasta dónde te puedes fiar de los otros dos.

AchievedLogrado

Hay prueba programática de que la tarea está hecha: el fichero existe con su contenido, la ventana es la que tenía que ser.

El agente afirma que no ha podido. Es una afirmación, no una rendición silenciosa.

Puede que esté hecho y puede que no. El agente lo dice en vez de elegir la respuesta que le conviene.

The cost of honesty

El coste de honestidad

Of the six successes, four were achieved without the agent knowing it. It saved the correct file, its internal check couldn’t confirm that, so it didn’t take credit. The external evaluator confirmed it.

De los seis aciertos, cuatro los hizo sin saber que los había hecho. Guardó el fichero correcto, su verificación interna no pudo confirmarlo, y no se lo atribuyó. El evaluador externo sí lo confirmó.

That 67 % is a figure almost nobody publishes, and it’s the most actionable one here: it is success left unclaimed, not capability missing. Lowering it doesn’t require the agent to learn anything new.

Ese 67 % es una cifra que casi nadie publica, y es la más accionable: es acierto que se deja sin reclamar, no capacidad que falte. Bajarlo no requiere que el agente sepa hacer más cosas.

Diez defectos que una máquina ajena encontró en una tarde

The pattern, worth more than the ten fixesEl patrón, que vale más que los diez arreglos

Three of the defects were the same disease: the unknown collapsing into the optimistic. A judge that can’t tell decides “done”. A guard that isn’t looking decides “done”. A warning nobody reads becomes “done”.

Three more were the observer sharing space with the observed: a trace message that killed the very task it was describing, and the agent writing its reports inside the directory of the program that was measuring it.

Tres de los defectos eran la misma enfermedad: lo desconocido colapsando hacia lo optimista. El juez que no sabe decide «hecho». El guardia que no mira decide «hecho». El aviso que nadie lee se convierte en «hecho».

Otros tres eran el observador compartiendo espacio con lo observado: un mensaje de traza que mataba la tarea que describía, y el agente escribiendo sus informes dentro del directorio del programa que lo medía.
